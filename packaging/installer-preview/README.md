# Installer look preview (developer tool)

Checks the branded setup UI (`packaging/installer-ui.nsh`) without building or installing the real app.
`preview.nsi` compiles a throw-away installer that copies dummy files to `%TEMP%`.

```powershell
# 1. compile (NSIS is downloaded by electron-builder on the first real build)
$mk = (Get-ChildItem "$env:LOCALAPPDATA\electron-builder\Cache\nsis-3.0.4.1" -Recurse -Filter makensis.exe | Where-Object { $_.FullName -notmatch 'linux|mac' } | Select-Object -First 1).FullName
# dummy payload (three folders of small files)
foreach ($g in "a","b","c") { New-Item -ItemType Directory -Force "payload\$g" | Out-Null; 1..10 | % { $b = New-Object byte[] 400KB; (New-Object Random $_).NextBytes($b); [IO.File]::WriteAllBytes("payload\$g\file$_.bin", $b) } }
& $mk /V2 /DAPP_KIND=employee '/DPRODUCT_NAME=AI BOS Employee' preview.nsi    # or admin / 'AI BOS Admin'

# 2. run it, click through, and save PNGs of the setup window (PrintWindow, DPI-aware)
.\capture.ps1 -Kind employee -Shots 1,3,8,18 -Clicks 2,3.6 -OutDir "$env:TEMP\aibos-installer-shots"
```

Add `/DAIBOS_DEBUG` to the compile line to log page geometry to `%TEMP%\aibos-ui-debug.txt`.

The artwork used by the installers is generated by `packaging/assets/installer/generate-installer-ui.ps1`.
